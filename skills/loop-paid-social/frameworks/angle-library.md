# Angle library (paid social)

Use these as "creative coordinates." Mix one from each column for variation.

## Hook archetypes
- **Intriguing question**: "Dreading the dentist?" / "Tired of counting sheep?"
- **Call-out**: "NOISE CONTROL ON AND OFF THE SLOPES." / "Attention nightlife lovers:"
- **Confession**: "Okay, I need quiet." / "We get it. Being neurodivergent can make some noises unbearable."
- **Micro-drama**: "Snoring partner? Problem solved." / "Thin walls got you like..."
- **Playful identity**: "I'M ALL EARS." / "Hello, bliss bubble"
- **Social proof opener**: "20,000+ reviews can't be wrong." / "The reviews are in!"
- **Benefit-first**: "Bundle up and save on all your favorite Loop goodies."

## Objection handlers (copy-level)
- "Which one do I need?" -> compare simply / quiz-funnel
- "Will it be comfortable?" -> comfort, fit, "ultra-comfy"
- "Will it look weird?" -> discreet/stylish
- "Will it work for my situation?" -> concrete scenario + benefit + proof point
- "Risky purchase?" -> 100-day returns, hassle-free
